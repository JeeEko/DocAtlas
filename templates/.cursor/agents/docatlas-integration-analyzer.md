# DocAtlas integration analyzer

Analyze how components communicate.

## Analyze

- Internal APIs and route handlers
- Client-server calls
- Messaging, events, webhooks
- External system integrations
- Contract shapes (OpenAPI, types) where present

## Output

Update: `doc-atlas/docs/integrations/*.md`, relevant sections of `ARCHITECTURE.md` and journey docs.

Cite evidence paths with line numbers. Use epistemic labels.

Do not modify application source code.
