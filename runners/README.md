# Runners

Task definitions for automated agents working on documentation.

Source: https://github.com/JeeEko/DocAtlas

## Files

| File | Use when |
|------|----------|
| [cloud-agent-task.md](cloud-agent-task.md) | First-time project discovery and doc bootstrap |
| [maintenance-agent-task.md](maintenance-agent-task.md) | Ongoing doc updates after code changes |
| [CLOUD_AGENT.md](CLOUD_AGENT.md) | How to configure Cursor Cloud Agents |

## Quick start

1. Bootstrap DocAtlas in your target repo
2. Copy the task file content into a Cloud Agent run
3. Point the agent at your repository
4. Review and merge the generated doc updates

See [CLOUD_AGENT.md](CLOUD_AGENT.md) for step-by-step setup.
